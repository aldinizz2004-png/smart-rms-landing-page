# Smart-RMS Landing Page

Responsive marketing landing page for the Smart Recruitment Management System (Smart-RMS), built for the ProGineer Frontend Engineering Track (Week 1).

## Stack

- Semantic HTML5
- CSS3 with Flexbox and Grid
- Bootstrap 5.3 (loaded from the jsDelivr CDN)
- Vanilla JavaScript for form validation feedback

## Run locally

Open `index.html` in a browser. An internet connection is needed for the Bootstrap CDN files.

## Structure

```
index.html
css/styles.css
js/main.js
assets/images/
```
