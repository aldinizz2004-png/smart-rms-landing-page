Smart-RMS architecture

Requests flow through five clear layers, from the browser down to the database.

  1. Presentation layer HTML5, CSS3 and Bootstrap 5 interfaces for recruiters and hiring managers.
  2. API layer ASP.NET Core Web API written in C# exposing the recruitment endpoints.
  3. Business layer Services that hold hiring rules, validation and role-based access checks.
  4. Data access layer Entity Framework Core and Dapper for reliable reads and writes.
  5. Database SQL Server storing jobs, candidates, applications and interviews.
